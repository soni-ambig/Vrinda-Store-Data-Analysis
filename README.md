# Vrinda Store Data Analysis

 📌 Project Overview
This project analyzes Vrinda store sales data to generate business insights.  
The goal is to identify sales trends, top-performing products, customer segments, and revenue patterns.

🛠️ Tools Used
- Excel (Pivot Tables, Charts, Dashboard)

 📊 Key Insights
- Most sales come from Maharashtra, Karnataka, and Uttar Pradesh.
- Women customers contribute more than men (~65%).
- The 30–49 age group is the largest customer segment.
- Amazon, Flipkart, and Myntra are the top sales channels.
